Rows are matched on date + shift + machine, so re-importing a corrected file updates those rows instead of duplicating them.

Which columns are needed

Daily report sheet — must have TGL, NO MC and PRODUKSI. Also read when present: SHIFT, MO, KODE KAIN, TYPE MC, KELOMPOK MESIN, JML KAIN, RPM, RPM TARGET, HIT RPM, KETIK RPM, KETIK PROD, KET BB.

Grade sheet — must have TGL, MO and A. Also read: KODE, B, BS, RK, TOTAL.

Header spelling is matched loosely, so Kelompok Mesin and KELOMPOK_MESIN both work. Rows without a real date — the SALDO opening balances — are skipped.
